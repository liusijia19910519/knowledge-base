# 知识库

独立知识库产品原型，包含主页、知识广场、共享知识库、个人知识库、回收站与问AI。界面固定展示当前用户周宁，协作成员仅用于内容授权；不提供身份预览切换或管理后台。

默认入口为独立产品说明页（`#/overview`），包含功能框架导图、50 项功能清单、权限规则、典型流程与体验范围，再由说明页进入原型。功能清单可搜索、按模块展开并导出 CSV。

库内新建和上传固定当前知识库，只有主页新建可选择目标库。普通移动、复制只在本库目录间进行；跨空间沉淀使用转共享和广场发布专用流程。分享只面向系统内部成员，不提供分享链接，新增查看权限须由创建者或管理者明确确认。

问AI采用简单的直接问答流程：选择知识或附件、提问、查看回答与引用、继续追问、管理历史，以及编辑、下载和保存结果到知识库。技能和专家为可选能力，不包含计划模式或未接入的联网搜索入口。

当前为本地交互原型：数据存储于浏览器，附件原文件保存在 IndexedDB，回答根据可读资料组织，不接入真实模型、组织登录或后端安全服务。示例组织是「北辰制造」。

公网预览由 GitHub Actions 在每次推送到 `main` 后发布。

```bash
npm ci
npm run dev
```
