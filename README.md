# 知识库

独立知识库产品原型。组织、团队、知识库和文档的权限在浏览器里演示，数据保存在本机，不会连接后端，也不会做真正的安全隔离。示例组织是「北辰制造」。

公网预览由 GitHub Actions 在每次推送到 `main` 后发布。

当前业务规则（2026-11-12）：知识库分为固定的个人、共享、广场类型。个人仅本人；共享可授权公司、部门、人员，授权全公司仍属于共享；广场始终保留公司全员查看，可额外授予更高权限。创建人及当前上级库／文件夹创建者的管理权受保护。

移动可跨三类知识库，需管理全部源内容并能编辑目标，移动后重新继承目标；进入个人库的所有内容必须由本人创建。复制需要查看、下载及目标编辑权限，生成独立新文件，由复制人成为创建人。

此轮使用新的原型数据版本，一次性重置旧样例和资源，不做旧分类迁移。按用户要求，本轮尚未运行构建、自动化测试或浏览器检查；待验收范围见 [PENDING_CHECKS.md](PENDING_CHECKS.md)，业务规则以 [AGENTS.md](AGENTS.md) 为准。

```bash
npm ci
npm run dev
```
