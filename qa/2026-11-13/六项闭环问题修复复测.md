# 六项闭环问题修复与复测

日期：2026-11-13。六项均已实施，并复用原 Ego 空间 5 逐项操作至最终结果。没有重置现有数据；测试仅新增测试资料，彻底删除仅用于本次创建的资源测试文件及临时知识库。

范围保持：原侧栏、卡片、列表、文件工作区布局；管理后台及 AI 功能未调整、未验收。创建人受保护管理权限、本人内容可移回个人库的规则不变。

## 修复内容

| 问题 | 实施结果 |
|---|---|
| 1. 恢复原位置绕过目标编辑权限 | 新增统一目标目录校验，创建／上传／移动／复制／恢复均复用；恢复原位置也必须具有当前编辑权限。失效或撤权时进入另选位置弹窗。 |
| 2. 编辑中离开导致草稿丢失 | 路由级拦截未保存修改，覆盖菜单定位、返回链接及浏览器后退；提供继续编辑／放弃／保存并继续。草稿按用户、文件、标签页保存在 sessionStorage，刷新后可恢复；保存或主动放弃后清除。失去查看权限时允许安全退出，草稿不对其他身份展示。 |
| 3. 缺少全局搜索 | 沿用侧栏搜索入口，通过轻量浮层跨个人／共享／广场检索知识库、文件夹和文件。名称与已有可检索正文支持多关键词，结果显示类型及路径，支持分类、键盘、加载更多和点击打开。各页面原局部搜索仍保留。 |
| 4. 恢复同名冲突缺少出口 | 回收站同名冲突进入可改名／另选位置弹窗；同位置改名恢复保留原授权，另选位置按目标规则重置普通授权。保留内容 ID、正文、创建人和原件引用，上传文件须保留扩展名。取消不修改原记录。 |
| 5. 上传刷新丢失任务 | 任务清单、原始待上传文件、目录映射持久化；提交文件与完成清单在同一次业务写入中确认，按任务 ID 防止重复提交。刷新后继续未完成任务；取消状态跨刷新保留，手动重试复用目录。准备阶段未保存原件时提供补选原文件入口。多标签页通过浏览器上传锁协调。 |
| 6. 彻底删除不释放资源 | 统一追踪原件、图标、封面及待上传源文件引用；回收站、其他副本、未完成任务仍引用的保留，失去最后引用后异步释放。清理队列持久化，失败后后续操作／启动可重试；写入前再次核对当前引用。 |

## 范围和边界

- 草稿按本浏览器标签页暂存，不提供跨设备草稿同步；原正文已在其他标签更新时仍保留冲突检查，不强行覆盖。
- 原件预存失败或准备阶段关闭时，刷新后可能需要用户补选原文件；文件名、大小和修改时间必须一致。任务不会重传已成功项。
- 原型仍使用本地存储，文件数和单文件大小限制不变。没有新增真实后台服务或多设备上传协议。
- 本轮回收明确失去最后引用的资源，不无条件扫描清空所有历史孤立 Blob；未删除其他业务数据。
- 极端存储服务持续不可用、跨浏览器兼容性、多个真实设备并发，以及之前明确暂缓的其他模块／视觉分支不宣称已全面验收。
